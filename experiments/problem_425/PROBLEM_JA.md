# Erdős problem #425 日本語訳（非公式）

出典:

- [Erdős problem #425](https://www.erdosproblems.com/425)
- [GitHub Issue #300: OEIS sequence for Erdős problem #425](https://github.com/teorth/erdosproblems/issues/300)
- [Erdős Problem a Day: working report for problem #425](https://erdosproblemaday.com/report/425)

## 問題文

`F(n)` を、次の性質を満たす集合

```text
A ⊆ {1, ..., n}
```

の要素数の最大値とする。すなわち、`A` から選んだ異なる二要素
`a < b` による積 `a*b` がすべて相異なるものとする。

このとき、次を満たす定数 `c` は存在するか。

```text
F(n) = pi(n) + (c + o(1)) n^(3/4) / (log n)^(3/2)
```

また、`A ⊆ {1, ..., n}` が、`a_1 < ... < a_r` に対する積
`a_1*...*a_r` がすべて相異なるという性質をもつとき、次は成り立つか。

```text
|A| <= pi(n) + O(n^((r+1)/(2r)))
```

ここで `pi(n)` は `n` 以下の素数の個数である。

## 条件について

最初の条件を明示的に書くと、`A` の二つの異なる二要素部分集合に
ついて

```text
{a, b} != {c, d} ならば a*b != c*d
```

が成り立つという意味である。二要素は異なるものを選ぶため、平方
`a*a` はこの条件に含まれない。

公式ページの最初の文では集合の上端が大文字の `N` となっているが、
その直後の式と問題の残りの部分に合わせ、この文書では `n` と解釈した。

## 今回の計算との関係

この問題が問うているのは `n` が無限に大きくなるときの漸近的な主張で
ある。`F(n)` の有限個の値を計算することだけでは、問題全体の解決には
ならない。

このディレクトリの二つのプログラムは、積を直接検査する方法と、積の
衝突から得られる禁止四要素集合を検査する方法により、`n = 1, ..., 20`
について次の値を再現した。

```text
F(1), ..., F(20) =
1, 2, 3, 4, 5, 5, 6, 6, 7, 7,
8, 9, 10, 10, 10, 11, 12, 12, 13, 13
```

上記の working report には、AI利用を明示した計算として `F(1)` から
`F(61)` までの値が既に掲載されている。したがって、ここでの `n <= 20`
の計算は新しい値の主張ではなく、異なる実装による再現である。

計算方法とAI利用上の注意については、同じディレクトリの `README.md`
を参照する。
